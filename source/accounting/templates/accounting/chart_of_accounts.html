{% extends "accounting/module_base.html" %} {% load static %} {% comment %} ============================================================================ accounting/templates/accounting/chart_of_accounts.html ---------------------------------------------------------------------------- The page shows one table. Each account category is a tab above the table. A control bar stays at the bottom of the page, below the table. The page needs one new style block. Add the block of chart_of_accounts.css to the end of accounting/static/accounting/css/accounting.css. The view sends these lists: asset_accounts · liability_accounts · equity_accounts income_accounts · expense_accounts Each account in a list can have these fields: code · name · type · balance is_debit / is_credit the color of the balance (both are optional) is_group a heading row inside the table (optional) The view also sends one total for each category: asset_total · liability_total · equity_total income_total · expense_total A list that the view does not send gives an empty table. Do not put a fallback in a filter argument, for example |default:accounts. A variable in that position must exist, or Django stops the page. The five tables are equal. Thus a change to one column must go into all five panels below. ============================================================================ {% endcomment %} {% block page_key %}accounts{% endblock %} {% block title %}Chart of Accounts · Accounting · Console{% endblock %} {% comment %} block.super keeps the buttons of the module base. {% endcomment %} {% block toolbar %}{{ block.super }}{% endblock %} {% block content %}
