Journal Entries

{% comment %} ====================================================================== THE TAB SET ---------------------------------------------------------------------- One table stays on the screen. Each journal is a tab. journals.js makes the change and writes the key into the URL, thus a link or a reload opens the same tab. Example: ?journal=sales Markup contract of the script: [data-tabset] the container [role="tab"][data-tab=KEY] the button [data-panel=KEY] the panel that the button shows The button also points at its panel with aria-controls. Each panel takes its own list from the view: general_entries · sales_entries · purchase_entries · cash_entries A list that the view does not send gives an empty table. Do not put a fallback in a filter argument, for example |default:entries. A variable in that position must exist, or Django stops the page with VariableDoesNotExist. Keep the fallback in the view. The four tables are equal. Thus a change to one column must go into all four panels below. ====================================================================== {% endcomment %}
