A format has a fixed length. The length splits into up to five segments, and each segment names one category: an acronym and a description. The category sets the letters that the segment contributes to the code. The strip and the segment list stay in step, because a color from the same six chart colors names a segment in both places, and again in the example code at the foot of the builder. The QR code and the barcode are dummy marks. Neither one decodes to a real value. They stand in the .code-swatch, the one light shape of the page, because a real mark needs a light ground to read at all. Code Management

A code format gives every asset, stock item or location a label of a fixed length. The length splits into segments, and each segment stands for one category: a location, a type, a year or a number in sequence. Build the format at the left, then generate the QR code or the barcode of the result at the right. A category comes from the library below, thus two formats can share the same category.
