{% extends "inventory/module_base.html" %} {% load fin stock %} {% comment %} ============================================================================ inventory/templates/inventory/analytics.html ---------------------------------------------------------------------------- The analytics page of the module. It holds five charts. The view gives the figures from the stock movements of the company (see analytics in views.py): the charts show the last 12 months, the figures and the table show the last 30 days. The module has no location and no minimum level yet, thus the page shows no figures for them. THE CHARTS The project has no chart library. Each chart is HTML, CSS and SVG: the columns a div for each month, with a height in a style attribute: style="height: 62%" the line an SVG polyline and one polygon below it the rank a track and a fill, with a width in a style attribute the ring an SVG circle for each part, with a length of the stroke and a start All colors come from the tokens of base.css and accounting.css. The classes are in inventory.css. Each chart sits in a .card of accounting.css. Thus it keeps the frame, the label and the space of a figure card. ============================================================================ {% endcomment %} {% block page_key %}analytics{% endblock %} {% block title %}Analytics · Inventory · Console{% endblock %} {% block content %}

Analytics

The analytics page shows the movement of the stock over time. The charts tell you what came in, what went out, what the stock is worth, and which items move most. Use the page to find the months in which the work uses more than the business receives.

The charts show the last 12 months. The figures show the last 30 days.
