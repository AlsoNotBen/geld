It holds six charts. THE CHARTS The project has no chart library, and a mockup does not need one. Each chart is HTML, CSS and SVG: the columns a div for each month, with a height in a style attribute: style="height: 62%" the line an SVG polyline and one polygon below it the rank a track and a fill, with a width in a style attribute the ring an SVG circle for each part, with a length of the stroke and a start All colors come from the tokens of base.css and accounting.css. The classes are in inventory.css. Each chart sits in a .card of accounting.css. Thus it keeps the frame, the label and the space of a figure card. Analytics

The analytics page shows the movement of the stock over time. The charts tell you what came in, what went out, what the stock is worth, and which items move most. Use the page to find the items that need a new minimum level, and the months in which the work uses more than the business receives.
