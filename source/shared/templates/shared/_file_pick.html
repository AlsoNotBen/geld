{% comment %} A file input with the look of a .tool button. The native input is hidden but stays in the tab order. base.js shows the name of the selected file, and in an .avatar-field it shows the image in the .avatar. Parameters: field (a Django form field), or input_id and name; has_avatar shows the Remove button. Remove sets avatar_clear to 1: the view then removes the avatar (filestore.services.update_avatar). Example:
{% verbatim %}{% avatar entity "lg" %}{% include "shared/_file_pick.html" with field=form.avatar %}{% endverbatim %}
{% endcomment %} {% if field %}{{ field }}{% else %}{% endif %} No image selected
